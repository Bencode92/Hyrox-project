# HyroxForge 🏋️‍♂️

**Ton coach IA personnel pour la préparation Hyrox.**

Application web de suivi et coaching sportif avec IA intégrée (Claude API via Cloudflare Worker). Focus : Running, Rowing, SkiErg.

## Features

- **Dashboard** — Score global /100, progression par pilier (Run 50%, Row 25%, Ski 25%)
- **Saisie de séances** — Run, Row, SkiErg avec tous les paramètres
- **Coach IA** — Analyse de séance, génération de la prochaine séance, plan semaine
- **Historique** — Graphiques d'évolution, filtres par type, suivi des deltas
- **Scoring automatique** — Algorithme local basé sur des barèmes de référence

## Stack

HTML/CSS/JS vanilla · Chart.js · Claude API (Sonnet) via Cloudflare Worker · GitHub Pages · LocalStorage
